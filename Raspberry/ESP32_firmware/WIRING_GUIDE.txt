================================================================================
  SMART CHESS BOARD — WIRING & HARDWARE GUIDE
  8x8 Matrix with Analog Linear Hall Effect Sensors
================================================================================

COMPONENTS
----------
  - 1x ESP32-WROOM-32 dev board
  - 2x CD74HC4067 16-channel analog multiplexer (breakout or DIP-24)
  - 64x Analog Linear Hall Effect Sensors (e.g. 49E / AH49E series)
  - Magnets in chess piece bases (neodymium, oriented consistently)
  - 2x WS2812B LED strips (76 LEDs per strip, 2 LEDs/square serpentine layout)


================================================================================
PIN ASSIGNMENTS — ESP32 to MUX & PERIPHERALS (analog_scanner.ino)
================================================================================

  ESP32 GPIO    Function                     Direction
  ----------    ---------------------------  ---------
  GPIO 25       Col MUX S0 (Ranks 1-8)       OUTPUT
  GPIO 26       Col MUX S1 (Ranks 1-8)       OUTPUT
  GPIO 27       Col MUX S2 (Ranks 1-8)       OUTPUT
  GPIO 14       Col MUX S3 (Ranks 1-8)       OUTPUT

  GPIO 16       Row MUX S0 (Files a-h)       OUTPUT
  GPIO 17       Row MUX S1 (Files a-h)       OUTPUT
  GPIO 18       Row MUX S2 (Files a-h)       OUTPUT
  GPIO 19       Row MUX S3 (Files a-h)       OUTPUT

  GPIO 34       MUX Analog Read (Col SIG)    INPUT (ADC1_CH6)
  GPIO 23       WS2812B Strip 1 Data (a-d)   OUTPUT
  GPIO 22       WS2812B Strip 2 Data (e-h)   OUTPUT

================================================================================
ANALOG HALL EFFECT SENSOR OPERATION
================================================================================

  - Sensor Type: Ratiometric Linear Hall Effect Sensors (e.g. 49E / SS49E).
  - Quiescent Output Voltage: ~VCC / 2 (~1.65V at 3.3V VCC, ADC ~2048).
  - Operation:
      * When NO magnet is near: Output sits at quiescent midpoint (~1.65V).
      * When a SOUTH magnetic pole approaches: Voltage increases towards 3.3V (ADC > 2048).
      * When a NORTH magnetic pole approaches: Voltage decreases towards 0V (ADC < 2048).
  - ESP32 ADC Configuration:
      * Attenuation: ADC_11db (0V to ~3.6V input range).
      * Resolution: 12-bit (raw values 0 to 4095).
  - Signal Conditioning:
      * Analog linear Hall sensors produce an active buffered analog voltage output.
      * Background calibration establishes quiescent baselines per square.
      * Piece placement is detected when raw ADC reading deviates beyond the baseline threshold.


================================================================================
WS2812B LED STRIP LAYOUT
================================================================================

  - Strip 1 (GPIO 23): Drives files a-d under ranks 1-8.
  - Strip 2 (GPIO 22): Drives files e-h under ranks 1-8.
  - Density: 2 LEDs per board square in a serpentine routing pattern.
  - Power: WS2812B strips run on external 5V power with shared GND.


================================================================================
NOTES & GUIDELINES
================================================================================

  - ESP32 GPIO 34 is input-only and used for ADC reading.
  - Avoid ESP32 strapping pins (0, 2, 5, 12, 15) and SPI flash pins (6-11) for general outputs.
  - Add 100nF decoupling capacitors between VCC and GND near each MUX chip.
  - Ensure all magnets in chess piece bases have consistent orientation across set pieces for uniform threshold direction.
