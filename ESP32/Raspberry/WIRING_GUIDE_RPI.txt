================================================================================
  SMART CHESS BOARD — WIRING GUIDE (Raspberry Pi 4)
  4x4 Prototype (scalable to 8x8)
================================================================================

COMPONENTS
----------
  - 1x Raspberry Pi 4 Model B
  - 2x CD74HC4067 16-channel multiplexer (breakout or DIP-24)
  - 16x Digital Hall effect sensors (active-low, e.g. A3144 / OH3144 / SS41)
  - 16x 10K ohm pull-up resistors (one per sensor output)
  - Magnets in chess piece bases (neodymium recommended)
  - 1x WS2812B LED strip (at least 16 LEDs, serpentine layout under the board)


================================================================================
PIN ASSIGNMENTS — Raspberry Pi 4 to MUX
================================================================================

  BCM GPIO    Phys Pin    Function            Direction
  --------    --------    ------------------  ---------
  GPIO 17     Pin 11      Row MUX S0          OUTPUT
  GPIO 27     Pin 13      Row MUX S1          OUTPUT
  GPIO 22     Pin 15      Row MUX S2          OUTPUT
  GPIO 5      Pin 29      Col MUX S0          OUTPUT
  GPIO 6      Pin 31      Col MUX S1          OUTPUT
  GPIO 13     Pin 33      Col MUX S2          OUTPUT
  GPIO 24     Pin 18      MUX Read (Col SIG)  INPUT
  GPIO 18     Pin 12      WS2812B Data (DIN)  OUTPUT (PWM0)

  Total: 8 GPIO pins used.

  HARDWIRED (not connected to RPi):
    - Both MUX S3 pins  --> GND  (limits to channels 0-7, enough for 8x8)
    - Both MUX EN pins  --> GND  (always enabled)

================================================================================
ROW MUX WIRING (CD74HC4067 #1 — Demux mode)
================================================================================

  Purpose: Selects which row of sensors is grounded (active).

  RPi GPIO 17   -->  Row MUX pin 10 (S0)     [Phys pin 11]
  RPi GPIO 27   -->  Row MUX pin 11 (S1)     [Phys pin 13]
  RPi GPIO 22   -->  Row MUX pin 14 (S2)     [Phys pin 15]
  GND           -->  Row MUX pin 13 (S3)     [hardwired]
  GND           -->  Row MUX pin 15 (EN)     [hardwired]
  GND           -->  Row MUX pin  1 (SIG)    [common pin to GND]
  3.3V          -->  Row MUX pin 24 (VCC)
  GND           -->  Row MUX pin 12 (GND)

  Row MUX pin  9 (C0)  -->  Row 0 sensors GND rail
  Row MUX pin  8 (C1)  -->  Row 1 sensors GND rail
  Row MUX pin  7 (C2)  -->  Row 2 sensors GND rail
  Row MUX pin  6 (C3)  -->  Row 3 sensors GND rail
  (For 8x8: also connect C4-C7 to rows 4-7)


================================================================================
COLUMN MUX WIRING (CD74HC4067 #2 — Mux mode)
================================================================================

  Purpose: Routes the selected column's sensor signal to the RPi read pin.

  RPi GPIO 5    -->  Col MUX pin 10 (S0)     [Phys pin 29]
  RPi GPIO 6    -->  Col MUX pin 11 (S1)     [Phys pin 31]
  RPi GPIO 13   -->  Col MUX pin 14 (S2)     [Phys pin 33]
  GND           -->  Col MUX pin 13 (S3)     [hardwired]
  GND           -->  Col MUX pin 15 (EN)     [hardwired]
  RPi GPIO 24   <--  Col MUX pin  1 (SIG)    [read signal, Phys pin 18]
  3.3V          -->  Col MUX pin 24 (VCC)
  GND           -->  Col MUX pin 12 (GND)

  Col MUX pin  9 (C0)  <--  Column 0 wire
  Col MUX pin  8 (C1)  <--  Column 1 wire
  Col MUX pin  7 (C2)  <--  Column 2 wire
  Col MUX pin  6 (C3)  <--  Column 3 wire
  (For 8x8: also connect C4-C7 to columns 4-7)


================================================================================
HALL SENSOR WIRING (per sensor)
================================================================================

  Each Hall effect sensor has 3 pins: VCC, GND, OUTPUT.

                    3.3V
                     |
                     +---------- Sensor VCC
                     |
                    [10K]  <-- pull-up resistor
                     |
  Sensor OUTPUT -----+---------- Column wire (to Col MUX channel)

  Sensor GND -------------------- Row wire (to Row MUX channel)


  The pull-up resistor holds the output HIGH by default.
  When a magnet is near AND the row is grounded by the MUX,
  the sensor pulls the output LOW.


================================================================================
WS2812B LED STRIP WIRING
================================================================================

  RPi GPIO 18   -->  Strip DIN (data in)     [Phys pin 12]
  RPi 5V pin    -->  Strip VCC               [Phys pin 2 or 4]
  RPi GND       -->  Strip GND               [shared ground]

  IMPORTANT: GPIO 18 (PWM0) is REQUIRED by the rpi_ws281x library.
  Do not use a different pin for the LED strip data line.

  RPi GPIO is 3.3V. WS2812B expects 5V data, but typically works with
  3.3V signals. For reliability, add a level shifter (3.3V → 5V) or
  place a 300-470 ohm resistor on the data line.

  Power: Each WS2812B LED draws up to 60mA at full white brightness.
  At 16 LEDs with brightness=50 and only a few lit, power draw is
  minimal (~50-100mA). The RPi 5V pin can supply this.
  For 64 LEDs (8x8), use an external 5V supply — NOT the RPi 5V pin.

  Add a 1000uF capacitor across the strip's VCC and GND (close to
  the strip power input) to smooth power spikes.


SERPENTINE LED LAYOUT (4x4)
----------------------------

  The LED strip zigzags under the board:

  Row 0 (even):  LED 0  → LED 1  → LED 2  → LED 3
                                                 |
  Row 1 (odd):   LED 7  ← LED 6  ← LED 5  ← LED 4
                  |
  Row 2 (even):  LED 8  → LED 9  → LED 10 → LED 11
                                                 |
  Row 3 (odd):   LED 15 ← LED 14 ← LED 13 ← LED 12

  Board square [row, col] maps to LED index:
    Even rows: index = row * BOARD_COLS + col
    Odd rows:  index = row * BOARD_COLS + (BOARD_COLS - 1 - col)


================================================================================
MATRIX TOPOLOGY (4x4)
================================================================================

                  Col 0       Col 1       Col 2       Col 3
                    |           |           |           |
                    |  [10K]    |  [10K]    |  [10K]    |  [10K]
                    +---|---    +---|---    +---|---    +---|---
                    |       |   |       |   |       |   |       |
  Row 0 ---[MUX]---GND  OUT|--GND  OUT|--GND  OUT|--GND  OUT|--
                    H[0,0]      H[0,1]      H[0,2]      H[0,3]

  Row 1 ---[MUX]---GND  OUT|--GND  OUT|--GND  OUT|--GND  OUT|--
                    H[1,0]      H[1,1]      H[1,2]      H[1,3]

  Row 2 ---[MUX]---GND  OUT|--GND  OUT|--GND  OUT|--GND  OUT|--
                    H[2,0]      H[2,1]      H[2,2]      H[2,3]

  Row 3 ---[MUX]---GND  OUT|--GND  OUT|--GND  OUT|--GND  OUT|--
                    H[3,0]      H[3,1]      H[3,2]      H[3,3]

  All sensor VCC pins --> 3.3V (shared rail, from RPi 3.3V pin)
  All pull-up resistors --> 3.3V (shared rail)
  Column wires --> Col MUX inputs (C0-C3)
  Row wires    --> Row MUX outputs (C0-C3)


================================================================================
POWER SUPPLY
================================================================================

  The RPi 4 should be powered by its USB-C port (5V 3A recommended).

  3.3V for MUXes and sensors comes from RPi's 3.3V pin (pin 1 or 17).
  The RPi 3.3V regulator can supply up to ~500mA — more than enough
  for 2 MUX chips (~1mA each) and 16 Hall sensors (~10mA each).

  5V for the WS2812B strip comes from RPi's 5V pin (pin 2 or 4).
  For 16 LEDs at low brightness this is fine. For 64 LEDs, use an
  external 5V power supply with shared GND.


================================================================================
SCALING TO 8x8
================================================================================

  1. Change BOARD_ROWS and BOARD_COLS to 8 in the .py files
  2. Add 48 more Hall sensors + pull-up resistors to the matrix
  3. Connect rows 4-7 to Row MUX channels C4-C7 (pins 5, 4, 3, 2)
  4. Connect cols 4-7 to Col MUX channels C4-C7 (pins 5, 4, 3, 2)
  5. Extend LED strip to 64 LEDs (same serpentine pattern continues)
  6. Use external 5V supply for the LED strip (not RPi 5V pin)
  7. No code changes needed — everything uses BOARD_ROWS/BOARD_COLS
  8. Same 8 GPIO pins, same 2 MUX chips


================================================================================
SOFTWARE SETUP
================================================================================

  1. Install dependencies:
       sudo pip3 install RPi.GPIO rpi-ws281x

  2. Both scripts must run as root (for GPIO and PWM access):
       sudo python3 hardware_test.py
       sudo python3 smart_chess_board.py

  3. If you get "RuntimeError: ws2811_init failed", make sure:
     - You are running with sudo
     - Audio output is set to HDMI (not headphone jack), because the
       headphone jack uses the same PWM channel as GPIO 18
     - No other process is using PWM0


================================================================================
NOTES
================================================================================

  - RPi 4 GPIO is strictly 3.3V. NEVER apply more than 3.3V to any
    GPIO pin — this will permanently damage the Pi. The CD74HC4067
    powered at 3.3V outputs 0-3.3V, which is safe.

  - The CD74HC4067 works at 3.3V (2V-6V range). ON resistance is ~70 ohm
    at 4.5V, slightly higher at 3.3V — fine for digital signals.

  - Add a 100nF bypass capacitor between VCC and GND on each MUX chip,
    placed close to the chip.

  - For reliable magnet detection, use neodymium magnets (6mm diameter,
    2-3mm thick works well) glued into the base of each chess piece.

  - GPIO pins used here avoid all special-function pins:
    Avoided: GPIO 0/1 (EEPROM), GPIO 2/3 (I2C with fixed pull-ups),
    GPIO 14/15 (UART), GPIO 7/8/9/10/11 (SPI).
